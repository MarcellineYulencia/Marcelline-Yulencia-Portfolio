# Marcelline Yulencia Portfolio

Live website: https://marcelline-portfolio.netlify.app/

This portfolio uses plain HTML, CSS, and JavaScript. No installation or build command is required.

## Update the website

Edit files in `dist`, then commit and push to `main`. Once the repository is connected to Netlify, successful pushes deploy automatically.

- `dist/index.html`: page content and sections
- `dist/app.js`: project descriptions, galleries, filters, and interactions
- `dist/*.css`: visual styling and responsive layout
- `dist/assets`: images, resume, APK, and complete Windows game download

Netlify publish directory: `dist`. Build command: leave empty.

The contact form opens an email draft in the visitor's email application. It does not send email automatically.

The Windows game ZIP must be fully extracted before running the executable.
